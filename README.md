# QSO Logger Frontend

Frontend application for the QSO Logger platform.  
Built with React, TypeScript, and Vite.

This project connects to the QSO Logger Backend API and provides a user interface for logging, viewing, and analyzing radio contacts.

---

## 🎯 Purpose

The frontend allows radio operators to:

- Log QSOs through a simple interface
- View and manage their contacts
- Explore DX statistics (distance, grids, countries)
- Visualize contacts geographically (map features)
- Interact with the backend API in real time

The current implementation is minimal, but structured to scale into a full-featured application.

---

## 🧩 Core Features (Planned & In Progress)

- Authentication (login/register)
- QSO logging form
- QSO list & filtering
- DX statistics dashboard
- Map visualization (grid-based)
- Confirmation status tracking
